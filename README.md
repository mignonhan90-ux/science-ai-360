# SCIENCE AI 360 — Cloud preview

Website demo KHTN 6–9, Hóa học chuyên sâu, API Python chuẩn thư viện, SQLite, giao diện navy–cyan.

**Triển khai trực tuyến:** đọc `HUONG_DAN_DUA_LEN_WEB.md`.

**Lưu ý:** bản xem thử chỉ dùng dữ liệu giả; chưa có AI ngôn ngữ, chưa đạt yêu cầu bảo mật để dùng trong trường học. Mặc định `ENABLE_DEMO_ACCOUNTS=0`, file `render.yaml` bật tài khoản demo cho mục đích xem thử.

Chạy tại máy: `python server.py`; kiểm thử: `python -m unittest discover -s tests -v`.
